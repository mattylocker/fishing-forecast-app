# Fishing Forecast App

A mobile-first bass fishing forecast app built as a personal summer project.

The goal of this project is to combine:
- live weather data
- water temperature
- lake conditions
- seasonal bass patterns
- lure and technique recommendations

into a simple fishing assistant focused on real-world bass fishing patterns.

---

## Features

### Current Features

- Mobile-first layout
- Live weather data
- Wind speed
- Cloud cover
- Rain chance
- Barometric pressure
- Sunrise and sunset
- Manual water temperature input
- Water clarity input
- Lake cover/type input
- Spawn pattern prediction
- Technique rating system

---

## Technique Ratings

The app predicts which fishing techniques should perform best based on:
- water temperature
- pressure
- cloud cover
- rain chance
- wind
- water clarity
- lake cover type

Example output:

- Swimbaits — Excellent
- Jigs — Good
- Topwater — Fair
- Finesse — Tough

---

## Spawn Pattern Logic

The app currently estimates:
- pre-spawn
- spawn
- post-spawn
- summer patterns

primarily from water temperature ranges.
